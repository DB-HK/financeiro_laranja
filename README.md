# Sistema de Gestão Financeira em Excel

Modelo de gestão e análise financeira desenvolvido em Microsoft Excel para controle financeiro e acompanhamento operacional de uma empresa.

A planilha foi originalmente desenvolvida para utilização empresarial e permanece em uso pela empresa para a qual foi criada. Esta versão foi adaptada e disponibilizada como portfólio, sem dados reais ou informações sensíveis.

## Funcionalidades

* Controle de lançamentos financeiros
* Fluxo de caixa diário
* Controle de entradas e saídas
* Acompanhamento de pagamentos
* Organização de dados financeiros
* Controle de fornecedores
* Controle e cálculo relacionado a notas fiscais
* Controle financeiro mensal
* Cálculo automático de resultados e saldos
* Planejamento e acompanhamento de atividades através de Gantt
* Integração entre diferentes módulos da planilha através de fórmulas e referências

## Estrutura

A planilha é composta por módulos independentes e interligados, incluindo:

* **Página Inicial** — visão geral das informações financeiras
* **Lançamentos** — registro de eventos, entradas, saídas e NFs
* **Dados** — base central de informações financeiras
* **Fornecedores** — cadastro e organização de fornecedores
* **NFE** — controle e cálculo de valores relacionados a notas fiscais
* **Gantt** — planejamento e acompanhamento de atividades
* **Janeiro a Dezembro** — acompanhamento financeiro mensal e cálculo de saldos

## Tecnologias e recursos

* Microsoft Excel
* Fórmulas e funções avançadas
* Tabelas estruturadas
* Referências entre diferentes abas e módulos
* Cálculos automatizados
* Formatação condicional
* Validação de dados
* Organização e modelagem de dados

## Objetivo

O objetivo do projeto foi centralizar diferentes processos financeiros e operacionais em uma única ferramenta, reduzindo controles manuais e automatizando cálculos e consolidações de informações.

## Observação

Esta é uma versão demonstrativa para fins de portfólio. Dados reais, informações confidenciais e elementos de identificação da empresa foram removidos ou substituídos.
